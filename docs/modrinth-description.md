# SnkMC Essentials

A client-side Fabric mod for the **SnkMC** server (`play.snkmc.net`). It reads what the game already shows you — item tooltips, server menus, the action bar — and turns it into clean HUDs and tooltips.

**Display only.** No macros, no auto-farming, no automatic clicks. The mod never sends a command or a click to the server, and it only activates on SnkMC.

## Features

**Parchment reader**

Scans the quest parchments in your inventory and shows each objective, its progress and its expiry in a HUD. Colour-coded by rarity.

**Weapons panel**

Lists your upgradable blades with their level, the XP left to the next level, and a marker when an ascension is available.

**Job HUD**

Level, XP and percentage of the job you are currently levelling, read live from the action bar while you harvest, mine, chop, fish or fight.

**Auction house prices**

Price per unit on stacks, and a colour band comparing a listing to its average price — yellow is cheap, green is fair, red is expensive.

**HUD editor and help**

Every HUD can be moved, resized or hidden: press `K`, drag with the mouse, scroll to resize, `Esc` to save. Press `H` for the in-game guide. The interface follows your Minecraft language (French or English).

**Update notifier**

Tells you in chat when a newer version is available on GitHub.

## Requirements

- Minecraft 26.1.2
- Fabric Loader 0.19.5 or newer
- Fabric API

## Privacy

The mod sends nothing to the SnkMC server. Anonymous usage statistics exist in the code but are **switched off** in this version. The only network call is the update check against GitHub.
